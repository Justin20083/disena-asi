# disena-asi

Skill con el estilo de diseño general de Justin: paletas, tipografía, layout editorial,
componentes, tokens, recetas maestras y checklist. Pensamiento permanente incluido:
toda IA que la instale debe leerla antes de diseñar o programar cualquier pieza visual.

## Instalación

### OpenCode / Codex / Cursor (skills)

Copia esta carpeta a tu directorio de skills:

```bash
mkdir -p ~/.config/opencode/skills/disena-asi
cp SKILL.md REFERENCIA-COMPLETA.md ~/.config/opencode/skills/disena-asi/
```

### Claude Code

```bash
mkdir -p ~/.claude/skills/disena-asi
cp SKILL.md REFERENCIA-COMPLETA.md ~/.claude/skills/disena-asi/
```

## Contenido

| Archivo | Qué es |
|---|---|
| `SKILL.md` | La skill: ADN visual, tokens obligatorios, recetas A–F, checklist pre-entrega |
| `REFERENCIA-COMPLETA.md` | Guía completa ficha por ficha (67 diseños únicos de referencia) |

## Actualización

Este estilo es general y vivo: se irá actualizando con nuevo material de diseño.
Cada cambio debe reflejarse en `SKILL.md` y, si aplica, en `REFERENCIA-COMPLETA.md`.
